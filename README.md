# 🎬 Movie Dashboard

A modern, responsive **black-themed movie dashboard** with a stylish login page, movie cards, sidebar navigation, and a cinematic interface.

🔗 **Live Repository:** https://github.com/himanshusapkota/Movie-Dashboard

## ✨ Features

- 🔐 Modern login page
- 🎬 Dark cinematic movie dashboard
- 🔎 Search bar
- 👤 User profile section
- 🎞️ Movie cards
- ⭐ Movie ratings
- 🧭 Sidebar navigation
- 📱 Responsive design
- ✨ Hover animations
- 🎨 Black and red theme
- 📐 Mobile-friendly layout

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
